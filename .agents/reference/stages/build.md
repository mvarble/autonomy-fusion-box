# The box's build

What `/wf-build` asks of the box besides what the skill says.

- **Before anything,** read the rules in `AGENTS.md`, above all the stamping rule.
- **A task that needs the hardware** is done by the user, or with them: say what to run and what to
  expect, and do not tick the box until they report the result.
- **The ledger.** Record anything the build teaches about a hardware fact in the ledger
  (`site/content/reference/open-questions/index.md`), which stays open at every stage.
- **When the hardware disagrees with a document,** stop as for a wrong plan, and suggest
  `/wf-reopen plan <reason>`.
